Responde con tus propias palabras.

1. ¿Qué significa repetir instrucciones en programación?

Respuesta: ciclo while

2. ¿Qué es un ciclo while?

Respuesta: Etuctura que control que permite repetir un conjunto de instrucciones.

3. ¿Qué significa la condición dentro de un while?

Respuesta: Detener el ciclo si la condicion es false.

4. ¿Por qué es importante cambiar una variable dentro del while?

Respuesta: permite que la condición del bucle eventualmente sea falsa,
 finalizando así la ejecución y evitando un bucle infinit

5. ¿Qué es un ciclo infinito?

Respuesta: conjunto de instrucciones que se repite indefinidamente
porque su condición de salida nunca se cumple o es siempre verdadera

6. ¿Qué hace el comando npm run practicar?

Respuesta: El comando npm run practica ejecuta un script personalizado
llamado "practica" definido en la sección "scripts" de tu archivo package.json.

7. ¿Dónde está definido el comando practicar?

Respuesta: modo practicar

8. ¿Qué diferencia hay entre node archivo.js y npm run practicar?

Respuesta: La principal diferencia radica en que node archivo.js
ejecuta un archivo directamente usando el motor de Node.js, 
mientras que npm run practicar ejecuta un comando predefinido en tu archivo package.json, 
gestionando el entorno y las dependencias del proyecto.

9. ¿Cómo puede servir un while para revisar varias fuentes de información?

Respuesta: El bucle while es una estructura de control fundamental para automatizar 
la revisión de múltiples fuentes de información porque permite repetir un conjunto de 
instrucciones mientras una condición específica sea verdadera. Es ideal para situaciones 
donde no se conoce de antemano el número exacto de fuentes o el tiempo que tomará procesarlas

10. ¿Cómo puede relacionarse un ciclo con el seguimiento de propuestas comunitarias?

Respuesta: Un ciclo de vida de proyecto se relaciona directamente con el seguimiento de 
propuestas comunitarias al estructurar el proceso en fases ordenadas, lo que permite monitorear 
el avance, evaluar resultados y ajustar acciones de manera participativa. El seguimiento no es 
una etapa aislada, sino un componente continuo y cíclico que vincula la planificación con los
resultados finales
